# Project Summary - March 4, 2026

## Overview
Today, we developed and deployed a gravity-themed personal webpage for **Hao**. The project involved creating an interactive frontend with unique CSS animations and setting up a version control workflow with GitHub.

## Completed Tasks

### 1. Web Development
- **Main Interface (`index.html`)**: Built an interactive single-page layout featuring a central astronaut card and orbiting skill planets (Python, C++, Deep Learning, Computer Vision).
- **Styling (`style.css`)**: Implemented a space-themed design system using "Glassmorphism" for the main card, a radial gradient background, and custom `float` keyframe animations to simulate a zero-gravity environment.
- **Dynamic Features (`script.js`)**: Added JavaScript to handle a gravity toggle button. When clicked, it disables the floating animations and applies gravity, simulating elements falling out of the screen.

### 2. Git & GitHub Integration
- **Local Initialization**: Managed the local Git repository for the project.
- **Successful Deployment**: Pushed the entire codebase to the remote repository: [https://github.com/monkeyhrq/Lecture-DIC1.git](https://github.com/monkeyhrq/Lecture-DIC1.git).

## File Structure
- `index.html`: Core structure and content.
- `style.css`: Visual design, layout, and zero-gravity animations.
- `script.js`: Interactive logic for the gravity toggle.
- `README.md`: This project documentation.
